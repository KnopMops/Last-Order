# Последний заказ (Last Order)

> **Атмосферный ретро-хоррор в эстетике конца 90-х.**  
> Смена в придорожном кафе «Тёплый угол» на глухом шоссе, где среди ночных посетителей скрываются двойники-мимики.

---

## 🎮 Об игре

Вы играете за Леру — ночную сменщицу кафе «Тёплый угол». Ваша задача — пережить 5 ночных смен (с 00:00 до 04:00), обслуживать гостей, поддерживать рассудок, следить за электропитанием и выявлять потусторонние аномалии.

* **2.5D вид сверху**: Исследование зала, кухни, подсобки и коридоров кафе, работа за стойкой, приготовление кофе и выпечка пирогов.
* **Тактический 3D-визор «ОКО-86» [V]**: Переход в режим от первого лица для сканирования зала, поиска скрытых кровавых разломов и уничтожения фантомов плазменным бластером.
* **Осмотр стекла [G]**: Двойники-мимики выдают себя за обычных посетителей, но у них нет отражения. Нажав `[G]`, вы можете осмотреть отражение зала и разоблачить самозванцев.
* **Мини-игры**: Калибровка осциллографа радиоприёмника (94.5 FM), починка звукоснимателя музыкального автомата «Мелодия-86», запуск генератора в подвале и погоня на ночном шоссе.

## 📦 Релизы и исполняемые файлы

При сборке проекта создаются два независимых бинарных файла:

1. **`Last Order.exe`** (Основной релиз):
   * Скомпилирован с флагом `-mwindows` — окно консоли (`cmd.exe`) **не появляется**.
   * Режим разработчика, debug-оверлей и горячие клавиши перемотки времени **отключены**.
   * Чистый игровой опыт для игроков.

2. **`Last Order_debug.exe`** (Режим разработчика):
   * Запускается со стандартной системной консолью для просмотра логов в реальном времени.
   * Активна клавиша **`[F2]`** — перемотка времени смены на +30 минут вперёд.
   * Активны клавиши **`[F3]`** / **`[F4]`** — debug-оверлей (FPS, координаты, noclip, статус аномалий).
   * Активна клавиша **`[N]`** — режим прохождения сквозь стены (Noclip).
   * Клавиши **`[1]`**–**`[5]`** — мгновенный запуск соответствующей ночи.

## 🛠️ Самостоятельная сборка проекта

### Требования

* **Операционная система**: Windows 10 / 11 (64-bit)
* **Компилятор C++**: MinGW-w64 GCC (версия 13+ с полной поддержкой C++20) или MSVC
* **Система сборки**: CMake 3.25 или новее
* **Git**

Библиотеки **raylib 5.5** и **nlohmann/json** загружаются и компилируются автоматически через CMake `FetchContent` — дополнительно устанавливать их не требуется.

---

### Быстрая сборка через `build.bat`

В корне проекта находится готовый скрипт автоматической сборки:

```bat
:: Собрать оба релиза и запустить Last Order.exe
build.bat

:: Только сборка (без автоматического запуска игры)
build.bat --no-run

:: Сборка и быстрый headless smoke-test (проверка корректности загрузки ассетов и рендера)
build.bat --smoke-test
```

После выполнения сборки готовые исполняемые файлы и папка `assets/` будут развёрнуты в каталог `release/`.

---

### Сборка вручную через CMake

```bash
# 1. Клонировать репозиторий
git clone https://github.com/KnopMops/Last-Order.git
cd Last-Order

# 2. Сгенерировать файлы сборки (MinGW)
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release

# 3. Скомпилировать проект в 8 потоков
cmake --build build -j 8
```

Готовые бинарные файлы будут находиться в папке `build/` (и автоматически скопированы в `release/`).

## 🕹️ Управление в игре

| Клавиша | Действие |
| :--- | :--- |
| **`[W, A, S, D]`** / Стрелки | Передвижение Леры по кафе |
| **`[E]`** | Взаимодействие (касса, правила, кофемашина, печь, радио, диалоги) |
| **`[G]`** | Осмотр стекла (проверка отражения зала для выявления мимиков) |
| **`[V]`** | Включение / выключение 3D-визора «ОКО-86» |
| **`[ЛКМ]`** / **`[ПРОБЕЛ]`** | Выстрел плазмой по аномалиям (в 3D-режиме) |
| **`[F]`** | Включение / выключение карманного фонарика |
| **`[TAB]`** | Тетрадь задач и текущие цели смены |
| **`[R]`** | Устав ночной смены кафе |
| **`[I]`** | Памятка сменщика (советы по механикам и приборам) |
| **`[F5]`** | Быстрое сохранение игры |
| **`[F11]`** | Переключение полноэкранного режима |
| **`[ESC]`** | Меню паузы / закрытие открытых окон и документов |

*В `Last Order_debug.exe` также доступны: `[F2]` (перемотка времени +30 мин), `[F3]/[F4]` (debug-информация), `[N]` (noclip), `[1..5]` (выбор ночи).*

## 💾 Настройки и сохранения

Все пользовательские данные хранятся изолированно в профиле пользователя Windows:
```
%APPDATA%\LastOrder\
  ├── settings.json       # Графика, звук, CRT-фильтр, яркость
  └── save_profile.json   # Прогресс ночи, рассудок, инвентарь
```

Если файлы отсутствуют, игра создаёт их автоматически с оптимальными настройками при первом запуске.
