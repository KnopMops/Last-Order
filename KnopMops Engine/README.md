# KnopMops Engine — Игровой 3D-движок и Редактор Карт

> **Автономная среда разработки и визуальный редактор карт (`.map`) в стиле Unity**  
> Создан специально для хорроров на выживание, ретро-FPS и квестов от первого лица.

---

## 🚀 Возможности редактора

* **Интерфейс в стиле Unity (Unity Dark Theme)**:
  * Полноценная система докинга окон (Dear ImGui Docking Branch).
  * **Scene Hierarchy**: дерево сущностей сцены с фильтрацией и контекстным меню.
  * **Inspector**: редактирование параметров брашей, текстур граней, UV-масштабирования и свойств сущностей.
  * **3D Viewport**: нативный рендер с интерактивным манипулятором трансформаций (ImGuizmo-style), сеткой и свободной камерой.
  * **Asset Browser**: предпросмотр текстур с возможностью наложения на грань в один клик.
  * **Map Generator**: процедурная генерация полых комнат с полом, стенами и потолком за 1 секунду.
  * **Console**: интерактивный лог событий и счётчики производительности (FPS, треугольники, браши).
* **Поддержка карт `.map`**:
  * Прямое чтение и запись карт в стандартном формате Quake / Valve 220 (`.map`).
  * Полная совместимость с игрой **«Последний заказ» (Last Order)** — созданные карты загружаются в игру без конвертации!
* **Удобное управление камерой**:
  * `[WASD] + Зажатая правая кнопка мыши`: свободный полёт (Flycam), `[Shift]` — ускорение.
  * `[Alt] + Зажатая левая кнопка мыши`: вращение вокруг выбранного объекта (Orbit).
  * `[Средняя кнопка мыши (колесо)]`: панорамирование (Pan).
  * `[F]`: мгновенный фокус на выбранном объекте.
  * `[W]`: режим перемещения (Move Gizmo).
  * `[E]`: режим вращения (Rotate Gizmo).
  * `[R]`: режим масштабирования (Scale).
  * `[Ctrl+D]`: дублирование выбранного браша/сущности.
  * `[Del]`: удаление объекта.

## 🛠️ Сборка и запуск

### Требования:
* Windows 10/11
* Компилятор C++20 (GCC 14+ MinGW-w64 или MSVC 2022)
* CMake 3.25+

### Быстрая сборка через командную строку:
```cmd
cd "e:\Projects\KnopMops Engine"
build.bat
```

Бинарный файл и ассеты автоматически разворачиваются в папку `bin/KnopMops Engine.exe`.
