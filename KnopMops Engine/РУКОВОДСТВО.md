# KnopMops Engine 1.0 — руководство

Универсальный движок и редактор для игр от первого лица на raylib. Принцип как в Unity/Godot:
**сцена → объекты (узлы) → компоненты → Lua-скрипты**. Работает на рантайме игры Last Order, поэтому всё,
что вы собрали и проверили кнопкой «Играть», в игре ведёт себя так же.

## 1. Запуск
* Редактор: `KnopMops Engine/bin/KnopMops Engine.exe` (сборка — `KnopMops Engine/build.bat`). Или `engine.bat` в корне репозитория.
* Проект для Last Order уже настроен: **`projects/last_order`** открывается по умолчанию (стартовая сцена: пол, игрок, лампа).
  Другие проекты: Файл → Открыть проект / Новый проект главы (проект создаётся пустым).
* Игра подхватывает проект после экспорта: `Last Order.exe --chapter last_order`
  (или меню «Выбор главы → Пользовательские главы»).

## 2. Окна
| Окно | Назначение |
|---|---|
| **Сцена** | 3D-вид уровня. Режим «Освещение (как в игре)» показывает лампы, ambient и текстуры как в игре. |
| **Игра** | Кнопка «Играть» (Ctrl+P) — прохождение прямо в редакторе. Клик — захват мыши, Esc — освободить. |
| **Иерархия** | Дерево узлов сцены, перетаскивайте объект на объект — вложение. ПКМ — меню (дубль, префаб, удалить). |
| **Менеджер сцен** | Список сцен (уровней) проекта: открыть (двойной клик), сделать стартовой, переименовать, дублировать, удалить, импорт карты. |
| **Инспектор** | Компоненты выбранного объекта, параметры скрипта, свойства узла; без выделения — настройки сцены (свет/туман). |
| **Файлы** | Проводник: проект, assets игры, карты игры (`data/maps`), все проекты. Двойной клик: `.lua` → редактор, `.map` → просмотр, `.kmprefab` → в сцену. ПКМ: удалить, импорт карты. Создание файлов и папок. |
| **Редактор скриптов** | Lua с проверкой синтаксиса, списком ошибок (клик — переход к строке) и справкой по API. |
| **Проект / Глава** | Скрипты, префабы, текстуры; настройки главы, предметы, проверка на софтлоки, экспорт. |

## 3. Управление в сцене
* **ПКМ + WASD/Q/E** — полёт, Shift — быстрее. **СКМ** — сдвиг. **Колесо** — масштаб. **Alt+ЛКМ** — вращение вокруг точки.
* **Home / «Вся карта»** — показать карту целиком; «Сверху» — вид сверху; **F** — фокус на выделенном.
* **ЛКМ** — выбрать. **Тяните сам объект мышью** — он едет по полу (с привязкой к сетке); тяните стрелки гизмо — по осям.
  **W/E/R/Q** — двигать/вращать/масштаб/выбор. Ctrl+D — дубль, Del — удалить, Ctrl+S — сохранить всё.
* Просмотр чужих карт: Файлы → «Игра: карты» → двойной клик по `.map`. Карта открывается только для просмотра
  (в проект не пишется); «Импорт как уровень» копирует её в проект.
* «Скрыть потолки» — чтобы видеть комнаты сверху.

## 4. Узлы и компоненты
**Узел** — любой объект сцены: просто точка (`Объект → Узел`), у которой есть имя, тег, позиция, вложенность и
**свойства** (Свойства узла: любые пары ключ=значение; из Lua: `self:get_prop("ключ")`, `self:set_prop("ключ", v)`).
К узлу добавляются компоненты («Добавить компонент»):
* **Меш** — вид (Cube/Sphere/Cylinder/None/Auto), текстура, цвет, свечение.
* **Свет** — точечная лампа (цвет, яркость, радиус, мерцание).
* **Коллайдер** — формы **Коробка / Сфера (круг) / Капсула**; размеры в метрах, смещение, «Триггер»; «Подогнать под модель» берёт размер из Scale.
* **Rigidbody** — масса, гравитация, кинематический, сопротивление, упругость, трение. Падает, отскакивает, лежит на браше/коллайдерах, игрок его толкает.
* **PlayerController** — ходьба/бег/присед/**прыжок**/гравитация/радиус и высота капсулы/чувствительность мыши.
* **Хоррор-компоненты:** Ящик (Search Slot), Укрытие, Дверь, Предмет, Маньяк (ИИ с патрулём и слухом).
* **Скрипт (Lua)** — файл + «Интерактивный» + параметры `exports`.
Физика приближает любые формы осевой коробкой по размеру коллайдера (простая и предсказуемая).

## 5. Скрипты (Lua)
Справка по всем функциям — окно «Редактор скриптов» → «Справка API» и `AGENTS.md`. Минимальный пример:
```lua
exports = { награда = "item_key" }
function on_interact(self)               -- игрок нажал E на объекте (включите «Интерактивный»)
  game.give_item(self.params.награда)
  game.notify("Нашли ключ!")
end
```
Физика из Lua: `self:add_force(0,5,0)`, `self:set_velocity(...)`, `game.raycast(x,y,z, dx,dy,dz, дальность)`.

## 6. Сцены (как в Unity)
Каждая сцена — файлы `levels/<имя>.kmscene` (объекты) и `levels/<имя>.map` (геометрия). В игре переход:
`game.load_level("имя")`. Стартовая сцена выбирается в Менеджере сцен. Инвентарь и переменные переходят между сценами.

## 7. Как создать главу
1. Менеджер сцен → «+ Новая сцена» (или импорт карты). 2. Постройте геометрию: «Инструменты карты» (комната), `Объект → 3D-объект → Стена/Пол-браш`
   и размеры в Инспекторе. 3. Расставьте объекты, лампы, игрока. 4. Напишите скрипты. 5. «Играть» — проверка.
6. Вкладка «Глава» → «Проверить» (ошибки Lua, софтлоки) → «Экспорт в игру» → «Запуск в игре».

## 8. Может ли ИИ (Claude) писать главы через движок?
**Да.** Всё, из чего состоит глава, — текстовые файлы: `chapter.json`, `levels/*.kmscene` (JSON), `levels/*.map`, `scripts/*.lua`,
`prefabs/*.kmprefab`. ИИ создаёт и правит их напрямую (формат описан в `AGENTS.md`), а вы открываете результат в редакторе,
смотрите в «Сцене», проходите кнопкой «Играть» и правите руками. Автопроверка: `KnopMops Engine.exe --selftest` (прохождение примера
`projects/bunker_demo`) и «Проверить главу» (Lua и софтлоки). Правки в самом движке (C++) — по правилам в `AGENTS.md`.

## 9. Частые вопросы
* *Сцена тёмная* — добавьте лампу (Объект → Точечный свет) или поднимите Ambient в Инспекторе (без выделения).
* *Нельзя пройти* — у игрока должна быть опора: пол-браш; коллайдеры осевые.
* *Нет звука* — пути вида `audio/sfx/имя.wav` из assets игры; свои — в `projects/<id>/audio/`.
* *Раскладка окон* — Окно → «Сбросить раскладку».
